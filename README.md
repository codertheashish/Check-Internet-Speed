# 🚀 Internet Speed Checker

A simple Python project that measures your internet connection's **Download Speed**, **Upload Speed**, and **Ping** using the Speedtest API.

## 📌 Features

* Check Download Speed (Mbps)
* Check Upload Speed (Mbps)
* Display Network Ping
* Simple and Beginner-Friendly Python Code

## 🛠️ Technologies Used

* Python 3
* speedtest-cli

## 📂 Project Structure

```text
Internet-Speed-Checker/
│
├── check_internet_speed.py
├── README.md
```

## ⚙️ Installation

1. Clone the repository:

```bash
https://github.com/codertheashish/Check-Internet-Speed.git
```

2. Navigate to the project folder:

```bash
cd Internet-Speed-Checker
```

3. Install dependencies:

```bash
pip install speedtest-cli
```

## ▶️ Usage

Run the Python file:

```bash
python check_internet_speed.py
```

Example Output:

```text
Download Speed in Mbps: 95.34
Upload Speed in Mbps: 47.21
Ping: 12.45
```

## 💡 How It Works

The program connects to the nearest Speedtest server and measures:

* Download Speed
* Upload Speed
* Network Latency (Ping)

Results are displayed in Mbps for easy understanding.
